## 2025-05-14 - Standard Search Input Pattern
**Learning:** A standard search input pattern includes a keyboard shortcut ('/') for quick focus, a clear button for efficiency, and a visual hint that fades out on focus to prevent overlap. Synchronizing the search icon color with the focus ring ('group-focus-within:text-secondary') provides better visual feedback.
**Action:** Implement this pattern for any search or filter input to improve keyboard accessibility and user efficiency.
