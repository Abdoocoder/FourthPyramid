## 2025-05-15 - Standard Search Input Pattern
**Learning:** A polished search experience requires more than just an input. Essential micro-interactions include: 1) A '/' keyboard shortcut for instant focus, 2) A visual `<kbd>` hint that disappears on focus or when text is present to avoid clutter, 3) A clear button ('X') that is explicitly `type="button"` to prevent form submission, and 4) Returning focus to the input after clearing to allow immediate re-typing.
**Action:** Always implement the shortcut hint and clear-focus loop for primary search bars.
