## 2025-05-22 - Standardized search input pattern
**Learning:** Combining a keyboard shortcut hint (`/`) that fades on focus with a clear button that returns focus provides a high-efficiency interaction loop for search-heavy pages like catalogs.
**Action:** Use 'group-focus-within:opacity-0' on keyboard hints to prevent visual overlap with user input, and ensure clear buttons are 'type="button"' to avoid accidental form submissions.
