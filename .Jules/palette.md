## 2025-05-23 - [Standard Search Pattern & Navigation Accessibility]
**Learning:** Implementing a standard search pattern (shortcut, hint, clear button) significantly improves discoverability. For navigation menus, using both `aria-hidden` and `inert` is necessary for robust accessibility across different screen readers and browsers.
**Action:** Always include a visual keyboard shortcut hint and ensure hidden interactive panels are correctly marked as `inert`.
